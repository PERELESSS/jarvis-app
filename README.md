# Jarvis

The built web app for HeyClaude's Jarvis (phone and browser), served by GitHub Pages at https://perelesss.github.io/jarvis-app/.

It holds no secrets: each computer is reached through its own Cloudflare tunnel, found and encrypted end to end with a link code that stays on the phone. Built from the HeyClaude repo with `npm run jarvis:deploy`; don't edit here.
